## About the Project

A single-page, responsive website built with Flexbox and Grid Layout.
The layout is pixel-perfect to the original design. Includes custom-built tabs written in vanilla JavaScript, without any third-party libraries.

## Technologies Used

- HTML5 (Twig)
- CSS3 (Flexbox, Grid)
- JavaScript (Vanilla JS)
